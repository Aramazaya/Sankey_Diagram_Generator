# Project Setup Summary

## Overview
This document summarizes the complete R project folder structure created for the Sankey Diagram Generator.

## Complete Folder Structure

```
SankeyDiagramGenerator/
├── .Rbuildignore                      # Files to exclude from package build
├── .gitignore                          # Git ignore patterns (already existed)
├── DESCRIPTION                         # Package metadata and dependencies
├── FOLDER_STRUCTURE.md                 # Detailed documentation of folder structure
├── LICENSE                             # MIT License text
├── NAMESPACE                           # Package exports (managed by roxygen2)
├── NEWS.md                            # Changelog for package versions
├── README.md                          # Main project documentation
├── SankeyDiagramGenerator.Rproj       # RStudio project configuration
│
├── R/                                 # R source code directory
│   ├── create_sankey.R               # Main function to create Sankey diagrams
│   ├── load_data.R                   # Functions to load data from files
│   └── prepare_data.R                # Data preparation and validation
│
├── data/                              # Directory for R data objects (.rda files)
│   └── (empty - ready for future data objects)
│
├── inst/                              # Additional package files
│   ├── examples/                      # Example R scripts
│   │   └── basic_usage.R             # Demonstrates basic package usage
│   └── extdata/                       # Sample data files
│       ├── sample_energy_flow.csv    # Energy flow example data
│       └── sample_workflow.csv       # Workflow example data
│
├── man/                               # Documentation (auto-generated)
│   └── (empty - will be generated by roxygen2)
│
├── tests/                             # Unit tests
│   ├── testthat.R                    # Test runner configuration
│   └── testthat/                     # Test files directory
│       └── test-sankey.R             # Tests for Sankey functions
│
└── vignettes/                         # Long-form documentation
    └── getting-started.Rmd           # Getting started tutorial
```

## Files Created

### Configuration Files
1. **DESCRIPTION** - Package metadata including:
   - Package name: SankeyDiagramGenerator
   - Version: 0.1.0
   - Dependencies: networkD3, dplyr, tidyr
   - Suggested packages: testthat, knitr, rmarkdown

2. **NAMESPACE** - Export declarations for:
   - create_sankey()
   - prepare_sankey_data()
   - load_data_from_csv()

3. **SankeyDiagramGenerator.Rproj** - RStudio project settings

4. **.Rbuildignore** - Excludes development files from package build

### Source Code (R/)
1. **load_data.R**
   - `load_data_from_csv()` - Load data from CSV files
   - Validates file existence and column structure
   - Standardizes column names

2. **prepare_data.R**
   - `prepare_sankey_data()` - Prepare data for visualization
   - Creates node list
   - Creates link list with indices
   - Returns structured list for networkD3

3. **create_sankey.R**
   - `create_sankey()` - Main function to create diagrams
   - Supports both data frames and prepared data
   - Customizable font size and node width
   - Returns interactive htmlwidget

### Sample Data (inst/extdata/)
1. **sample_energy_flow.csv**
   - 11 rows of energy distribution data
   - Shows flows from Energy → types → end uses

2. **sample_workflow.csv**
   - 9 rows of project workflow data
   - Shows flows from Departments → Projects → Output

## How to Use This Project

### 1. Install the Package
```r
# From source
install.packages("path/to/SankeyDiagramGenerator", repos = NULL, type = "source")

# Using devtools
devtools::install_local("path/to/SankeyDiagramGenerator")
```

### 2. Load and Use
```r
library(SankeyDiagramGenerator)

# Create from data frame
data <- data.frame(
  source = c("A", "B", "C"),
  target = c("X", "Y", "Z"),
  value = c(10, 20, 15)
)
create_sankey(data)

# Load from CSV
data <- load_data_from_csv("data.csv")
create_sankey(data)
```

### 3. Development Workflow
```r
# Document functions
devtools::document()

# Run tests
devtools::test()

# Check package
devtools::check()

# Build package
devtools::build()
```
