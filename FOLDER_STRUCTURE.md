# R Project Folder Structure for Sankey Diagram Generator

This document describes the folder structure and organization of this R package project.

## Directory Structure

```
SankeyDiagramGenerator/
│
├── R/                          # R source code (REQUIRED)
│   ├── load_data.R            # Data loading functions
│   ├── prepare_data.R         # Data preparation and validation
│   └── create_sankey.R        # Main Sankey diagram creation functions
│
├── man/                        # Documentation files (auto-generated by roxygen2)
│   # Generated automatically - do not edit manually
│
├── tests/                      # Unit tests (using testthat framework)
│   ├── testthat.R            # Test runner script
│   └── testthat/             # Individual test files
│       └── test-sankey.R     # Tests for Sankey functions
│
├── inst/                       # Additional files to be installed with package
│   ├── extdata/              # Example/sample data files
│   │   ├── sample_energy_flow.csv
│   │   └── sample_workflow.csv
│   └── examples/             # Example R scripts
│       └── basic_usage.R     # Basic usage examples
│
├── vignettes/                  # Long-form documentation and tutorials
│   └── getting-started.Rmd   # Getting started guide
│
├── data/                       # Processed R data objects (optional)
│   # For .rda/.RData files that users can load with data()
│
├── DESCRIPTION                 # Package metadata (REQUIRED)
│   # Contains package name, version, author, dependencies, etc.
│
├── NAMESPACE                   # Package exports and imports (REQUIRED)
│   # Defines which functions are exported and which packages are imported
│
├── SankeyDiagramGenerator.Rproj  # RStudio project file
│   # Configuration for RStudio IDE
│
├── .Rbuildignore              # Files to ignore when building package
│   # Lists files that shouldn't be included in package bundle
│
├── .gitignore                 # Git ignore rules
│   # Specifies which files Git should ignore
│
├── LICENSE                    # License text
│   # Full text of the MIT license
│
├── NEWS.md                    # Changelog
│   # Documents changes in each version
│
└── README.md                  # Project overview and quick start guide
    # First file people see on GitHub

```

## Key Directories Explained

### R/ (Required)
- Contains all R source code
- Each file should contain related functions
- Use roxygen2 comments for documentation
- Files are loaded alphabetically when package loads

### man/ (Generated)
- Auto-generated by roxygen2 from R/ comments
- Do not edit manually - edit roxygen comments instead
- Contains .Rd files (R documentation format)

### tests/
- Contains unit tests using testthat framework
- testthat.R is the test runner
- Individual test files go in tests/testthat/
- Test files should start with "test-"

### inst/
- Files here are installed with the package
- Access files using system.file()
- Common subdirectories:
  - extdata/ - example data files
  - examples/ - example scripts
  - templates/ - template files

### vignettes/
- Long-form documentation in R Markdown format
- Compiled to HTML during package build
- Great for tutorials and detailed examples

### data/ (Optional)
- For processed R data objects (.rda, .RData)
- Users can load with data(dataset_name)
- Document in R/data.R file

## Required Files

### DESCRIPTION
- Package metadata
- Specifies dependencies
- Contains version information
- Required for R packages

### NAMESPACE
- Controls which functions are exported
- Manages package imports
- Generated by roxygen2

### README.md
- Project overview
- Installation instructions
- Quick start examples
- Visible on GitHub

## Best Practices

1. **One function per file** or group related functions
2. **Document everything** using roxygen2 comments
3. **Write tests** for all functions
4. **Include examples** in function documentation
5. **Create vignettes** for complex workflows
6. **Keep data separate** from code
7. **Use consistent naming** conventions
8. **Version control** everything except generated files

## Workflow

1. **Write code** in R/ with roxygen2 comments
2. **Generate documentation**: `devtools::document()`
3. **Write tests** in tests/testthat/
4. **Run tests**: `devtools::test()`
5. **Check package**: `devtools::check()`
6. **Build package**: `devtools::build()`
7. **Install locally**: `devtools::install()`
